# Privacy Policies

Public privacy policies for apps published by Noble Technologies, served with GitHub
Pages. This repository must stay **public** — GitHub Pages only builds from a private
repository on a paid plan, and Google Play requires the policy URL to be publicly
reachable and non-geofenced.

## Adding a policy for a new app

1. Create a folder named after the app, e.g. `my-app/`.
2. Put the policy in it as `index.html`, which gives a clean URL with no `.html` suffix.
3. Add a link to it in the root `index.html`.

## Requirements Google Play enforces

A policy URL is rejected unless it is publicly accessible, non-geofenced, not a PDF,
non-editable, and renders without JavaScript. It must also name the app or the
developer entity shown on the store listing.

## Enabling Pages

Repository **Settings → Pages → Source: Deploy from a branch**, branch `main`, folder
`/ (root)`. The site is live a minute or so later.
